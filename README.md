# Royal Haveli

### Indian Fine Dining • San Jose, California

A premium restaurant website created for **Royal Haveli**, showcasing its dining experience, cuisine, atmosphere, menu, and reservation experience through a refined digital interface.

**Live Website:**
https://royalhavelisj.com/

## About the Project

Royal Haveli is a modern digital experience designed to reflect the restaurant's elegant identity and premium dining atmosphere.

The website combines sophisticated visual design with smooth interactions, responsive layouts, and intuitive navigation to provide an engaging experience across desktop, tablet, and mobile devices.

## Local Development

### Requirements

Make sure you have **Node.js** installed on your system.

### Installation

Clone the repository and install the project dependencies:

```bash
npm install
```

### Start Development

Run the development server:

```bash
npm run dev
```

Vite will provide the local development URL in the terminal.

---

## Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
